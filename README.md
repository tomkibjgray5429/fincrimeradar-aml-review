## Overview

FinCrimeRadar gives compliance users a browser-based way to examine names and entities against public sanctions lists, PEP information, and adverse media sources. The interface is intended to keep risk-signal review accessible while supporting open-source, public-data workflows.

The application also serves as an educational resource for AML screening and financial crime monitoring. Users can study compliance review methods, experiment with screening concepts, and prototype workflows without depending on a large or complex platform. A public API and knowledge hub provide additional options for integration, learning, and reference.

## Using FinCrimeRadar

The basic process is to provide a subject for review, run the applicable checks, and assess the returned sanctions, PEP, and adverse media information.

A representative workflow looks like this:

1. Load the application in a modern browser
2. Enter a person, company, or other entity
3. Submit the subject for screening
4. Examine matches and the related public-data references
5. Review results across the sanctions, PEP, and adverse media sections
6. Connect the public API to another workflow when external integration is needed

When hosted as a static web project, screening is performed through the browser interface. Integrations can use the project's API endpoints to invoke or extend the available screening behavior.
